模块以 `main.py` 为进程入口，通过 FastAPI lifespan 在启动时初始化 Milvus 客户端、嵌入模型、asyncpg 连接池，并可选地拉起 gRPC Query RPC 服务器与 NATS parse_worker；路由按职责拆分为 `app/routers/documents.py`（文档解析/删除索引）和 `app/routers/query.py`（RAG 查询），二者共享 `app/services/qa_service` 与 `retrieve_service` 实现相同的检索逻辑。
- 配置集中由 `app/core/config.py` 的 Pydantic `Settings` 管理，支持从 `.env` 与环境变量注入，并通过 `field_validator` 将 `milvus_addr` 拆分为主机与端口。
- 基础设施抽象位于 `app/core/`：`milvus.py` 封装 Milvus 集合操作，`embeddings.py` 封装远程 OpenAI 兼容嵌入端点调用，`config.py` 暴露全局 `settings`。
- 依赖方向单向：routers → core + services → 外部系统（Milvus、PostgreSQL/pg_trgm、NATS、MinIO、vLLM/OCR API、Redis ChatMemory）；gRPC 与 parse_worker 通过延迟 import 避免启动期强依赖。
- 健康检查 `/health` 暴露各组件就绪状态，便于编排层探测。
