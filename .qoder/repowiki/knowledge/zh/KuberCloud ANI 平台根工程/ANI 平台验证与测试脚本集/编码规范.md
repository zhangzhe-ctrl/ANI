- 脚本入口统一使用 `if __name__ == "__main__": raise SystemExit(main())` 模式，并通过 `argparse` 解析可选参数。
- Live Gate 类脚本成对出现同名 `_test.py` 单元测试，使用 `unittest.TestCase` 与被测模块同目录导入。
- 契约校验脚本将规则常量（如 `RULES`、`REQUIRED_MODES`、`FORBIDDEN_COMPONENTS`）集中在模块顶部，便于集中维护与扩展。
- HTTP 请求封装为带 `Authorization`、`X-Tenant-ID`、`Idempotency-Key` 头部的通用函数，错误响应统一解析 JSON 并返回状态码+文档。
- 失败路径统一抛出 `RuntimeError` 或 `SystemExit`，由外层测试框架捕获并输出诊断信息。
- 跨脚本共享的公共能力（如 `gateway_url`、`wait_for_state`、`require_instance`、`run_kubectl`）抽取到独立的 validate_* 模块供多个 live gate 复用。
