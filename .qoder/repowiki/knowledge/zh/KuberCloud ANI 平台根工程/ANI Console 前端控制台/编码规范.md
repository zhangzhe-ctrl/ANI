- 所有 HTTP 请求通过 `openapi-fetch` 生成的 typed client（`api` / `coreApi`）发起，禁止手写 fetch 调用以保证类型安全。
- 鉴权逻辑集中在 `src/api/auth.ts`，通过 `setAuthToken` 注入 Bearer Token，并在 `onRequest`/`onResponse` 中间件中统一处理 401 刷新与登出跳转。
- 路由采用文件系统约定式路由，受保护页面统一放在 `_authenticated/` 目录下，动态路由使用 `$paramName` 命名（如 `$kbId`）。
- OpenAPI 契约变更通过 `package.json` 的 `gen-api` 脚本重新生成 `schema.d.ts` 与 `core-schema.d.ts`，避免手写接口定义。
- 演示态与生产态共享同一 UI 骨架，`App.tsx` 通过 `window.location.pathname === '/demo-console'` 切换 DemoConsolePage，其余视图走 MockConsolePage。
