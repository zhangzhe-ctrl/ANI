模块以 Vite + React 18 为构建与运行时，入口 `src/main.tsx` 初始化 TanStack Query、挂载 TDesign MessagePlugin、通过 `hydrateSession` 恢复本地会话并注入 Bearer Token，再创建 Router 并渲染根路由树。
- 路由层：使用文件系统路由（`src/routes/*`），由 `@tanstack/router-plugin` 在 `vite.config.ts` 中生成 `routeTree.gen.ts`；受保护路由集中在 `_authenticated/` 目录，业务路由按领域分目录（`kb/$kbId/chat.tsx`、`models/`、`settings/`、`usage.tsx`）。
- API 层：`src/api/client.ts` 基于 `openapi-fetch` 生成类型安全的 Services API 客户端（baseUrl `/api/v1/svc`），`coreClient.ts` 对接 Core API；两者共用 `src/api/auth.ts` 中的请求/响应中间件，统一处理 Bearer 注入、401 刷新与跳转登录。
- 鉴权：`src/auth/session` 负责 access_token / refresh_token 持久化与过期判断，`auth.ts` 实现 token 注入、refresh 重试、logout 及 returnTo 流程。
- 演示模式：`App.tsx` 内置 MockConsolePage 与 demo 页面（`demo/InstanceDemoPage`、`demo/DemoConsolePage`），用于无后端联调。
- 代码生成：`scripts/gen-core-schema.mjs` 对 `api/openapi/v1.yaml` 做 YAML 语法归一化后再生成 `src/api/core-schema.d.ts`，配合 `package.json` 的 `gen-api` 脚本完成双契约类型生成。
