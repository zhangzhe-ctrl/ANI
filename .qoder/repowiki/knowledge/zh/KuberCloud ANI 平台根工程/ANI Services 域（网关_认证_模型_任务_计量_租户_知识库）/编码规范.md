- 每个服务目录包含独立的 go.mod、Dockerfile 和 main.go，遵循单进程单职责的可部署单元模式
- 配置统一通过 internal/config 包加载，测试通过 integration_test / *_test.go 覆盖
- 跨服务通信采用 gRPC 或 OpenAPI 契约，禁止在子服务间直接 import 共享 Go 包
- 需要可靠事件投递的服务（task-service、metering-service）使用 Outbox 模式将事件先落库再异步发布
- Gateway 侧所有横切关注点（鉴权、限流、幂等、审计、RBAC）以中间件形式集中实现并在 router 装配
