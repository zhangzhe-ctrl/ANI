模块采用经典的三层结构：`main.go` 作为入口，使用 `bootstrap.Config` 加载环境变量并通过 `bootstrap.MustConnect` 建立共享依赖（DB/NATS/Redis），再组装 `repo.PostgresModelRepo` 与 `service.ModelService`，最后由 `bootstrap.RunGRPC` 启动 gRPC 服务器并注册服务。
- `internal/config`：仅负责从环境变量读取配置（DATABASE_URL、NATS_URL、REDIS_URL、GRPC_PORT、HEALTH_PORT、ServiceName），并提供默认值。
- `internal/service`：实现 `modelv1.ModelServiceServer`，处理请求校验（名称正则、版本格式白名单 safetensors/gguf/pytorch、加密算法 sm4/zuc/aes256gcm）、租户上下文注入（`withTenant`）、事务边界（Begin/Commit/Rollback）以及领域错误到 gRPC status code 的映射（`toStatus`）。
- `internal/repo`：定义 `ModelRepo` 接口并由 `PostgresModelRepo` 实现，使用 `jackc/pgx/v5` 直接编写 SQL，按 `tenant_id` 进行多租户隔离（通过 `types.SetDBTenant` 在事务中设置），支持软删除（status='deleted'）和游标分页（`types.EncodeCursor`/`DecodeCursor`）。
- 依赖方向严格单向：`service` → `repo` → pgx；`main` 仅做装配。未实现的 gRPC 方法（上传/下载 URL、Import）以 `Unimplemented` 返回占位。
