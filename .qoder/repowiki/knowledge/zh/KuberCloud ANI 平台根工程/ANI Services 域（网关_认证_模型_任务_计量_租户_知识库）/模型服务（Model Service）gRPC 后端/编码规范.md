- 所有写操作（Create/Delete/CreateVersion）在服务层显式开启事务（db.Begin），并使用 defer rollback 确保失败回滚，成功后 Commit。
- Repository 层对需要读操作的查询通过 `beginTenantTx` 自行开启事务并在末尾 Commit，对写入操作则接收外部传入的 tx 参数。
- 多租户隔离通过在事务开始时调用 `types.SetDBTenant(ctx, tx)` 注入 tenant_id，并在查询条件中过滤 `status <> 'deleted'` 实现软删除。
- 领域错误统一封装为 `types.ErrNotFound/ErrBadRequest/ErrConflict/ErrForbidden/ErrUnauthorized`，再由 `toStatus` 映射为对应的 gRPC codes（NotFound/InvalidArgument/AlreadyExists/PermissionDenied/Unauthenticated/Internal）。
- 请求参数在进入业务逻辑前集中校验：租户 ID 与资源 ID 通过 `parseTenant`/`parseTenantAndID` 解析，模型名用正则 `^[a-z0-9][a-z0-9.-]{0,62}$` 校验，版本格式与加密算法走白名单 switch。
- 未实现或待接入的外部能力（MinIO 预签名 URL、Import 异步任务）以返回 `codes.Unimplemented` 的方式预留接口位置。
