模块以 router.go 中的 RegisterWithOptions 为唯一入口，通过 RegisterOptions 注入各后端服务接口（ports.*），按 URL 前缀分组注册：根组暴露 /healthz、/readyz；/api/v1 下注册品牌、任务、鉴权、计量、镜像仓库、实例、可观测性、GPU 库存与调度、网络、存储、向量库、K8s 集群、加密、密钥、邮件通知、配额等资源；/api/v1/svc 下注册模型、推理服务、知识库、GPU 容器、沙箱、租户等过渡型服务；/v1 提供 OpenAI 兼容的 chat/completions 与 inference/stream 代理。每个资源文件定义一个 registerXxx 函数，集中声明该资源的所有路由并构造对应的 API struct（如 authAPI、kbAPI）持有注入的后端客户端。依赖方向单向指向 middleware（获取 tenant/user/request_id）、ports（服务抽象）和 pkg/generated/pb（gRPC proto 类型），路由层仅做请求绑定、参数校验、错误码映射与 JSON 序列化，不执行业务逻辑。未就绪的后端通过 stubs.go 返回 501，或像 KB gRPC 客户端为空时返回 503，保证网关在无可选依赖的环境也能启动。
