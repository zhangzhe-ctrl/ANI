- 每个资源文件定义一个 registerXxx(routerGroup) 函数集中声明该资源的全部路由，并在其中构造携带注入后端的 API struct 实例。
- Handler 采用「thin wrapper + handler」模式：HTTP 方法只做 BindJSON/参数校验，再调用同名 xxxHandler 返回 (response, httpStatus, errorCode, message)，由 wrapper 统一写 JSON。
- gRPC 错误通过 status.FromError / status.Code 分支映射为 HTTP 状态码与统一错误码（如 UNAUTHORIZED、BAD_REQUEST、AUTH_NOT_CONFIGURED、NOT_FOUND）。
- 可选后端依赖在 handler 入口处判空，返回 503 UNAVAILABLE 或 501 NOT_IMPLEMENTED，保证网关在缺少某服务时仍可启动。
- 响应体结构体字段使用 json tag 严格对齐 services/v1.yaml 契约，proto 对象通过独立的 xxxToJSON 转换函数处理时间戳为 RFC3339 字符串。
- 错误响应统一通过 writeAuthError/writeInstanceError 输出包含 code、message 与 request_id 的 JSON 结构，request_id 从 middleware.GetRequestID 读取。
