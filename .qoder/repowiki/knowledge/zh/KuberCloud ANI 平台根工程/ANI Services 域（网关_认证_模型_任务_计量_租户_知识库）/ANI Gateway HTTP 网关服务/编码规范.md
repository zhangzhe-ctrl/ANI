- 每个后端能力以独立的 *_runtime.go 文件实现 Provider Runtime，由 main 集中构造并通过 router.RegisterWithOptions 注入路由层。
- 横切关注点（鉴权、RBAC、限流、幂等、审计、请求 ID）集中在 internal/middleware，通过统一的 Register 函数按固定顺序挂载到 Hertz 中间件链。
- 路由处理器位于 internal/router，按资源域拆分为单独文件并以 *_resources.go 命名，测试文件一一对应。
- 所有外部依赖（Redis、K8s、gRPC、Prometheus 等）均通过环境变量配置，main 中提供 *ConfigFromEnv 函数统一解析。
