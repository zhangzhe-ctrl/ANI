入口 main.go 负责生命周期：解析环境变量构建 Redis store、K8s 集群代理、加密/密钥/GPU/网络/存储/镜像仓库/实例/向量库/可观测性/kb-service gRPC 等运行时对象，再通过 middleware.Register(h, gatewayStore) 注入鉴权、RBAC、限流、幂等、审计等横切能力，最后调用 router.RegisterWithOptions 把上述运行时以结构体字段形式注入路由层；router 按 /api/v1、/api/v1/svc、/v1 OpenAI 兼容路径分发到具体 handler，handler 再调用对应 Provider Runtime 完成实际 I/O。中间件与路由通过共享的 Hertz server 实例和统一的 Store（Redis）解耦，新增业务只需在 runtime_handlers 中提供 Provider Runtime 并在 router 中注册即可。
