- 每个中间件暴露无参工厂函数（如 `Auth()`、`RBAC()`、`RateLimit(store)`）和带依赖注入的 `*WithClient` / `*WithStore` 变体，便于测试时替换依赖。
- 中间件对公共健康检查与认证入口路径通过 `isPublicPath` 白名单判断后直接 `c.Next(ctx)` 放行，避免重复鉴权逻辑。
- 错误响应统一通过 `respondError(c, statusCode, code, message)` 输出包含 `code`、`message`、`request_id` 的标准 JSON 结构并调用 `c.Abort()` 终止链式处理。
- 跨中间件共享状态通过 `RequestContext` 的 key-value 存取（如 `tenant_id`、`user_id`、`roles`、`scope`、`request_id`），并提供 `GetTenantID`/`GetUserID`/`GetScope`/`GetRequestID` 等 getter 封装。
- 对外部服务的调用通过接口（`AuthClient`、`GatewayStore`）解耦，并在 `Register` 中集中组装，中间件内部不直接构造 gRPC 连接或缓存实例。
- 沙箱 token、平台 token、租户 token 通过 `scopeAllowedForPath` 与 `inferPermission` 按前缀与 HTTP 方法映射到资源:动作进行权限判定，形成统一的 scope 路由隔离策略。
