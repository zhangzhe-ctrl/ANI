- 每个 Provider 提供一对 `gateway*RuntimeConfigFromEnv` 读取环境变量 + `newGateway*Service` 构造实现的函数，按 `ProviderMode` 分支选择具体后端并返回带关闭函数的 service。
- 路由处理器按资源域拆分为独立文件，并在 `router.go` 的 `RegisterWithOptions` 中集中注册，通过 `RegisterOptions` 结构体注入依赖，避免包级全局耦合。
- 中间件以固定顺序通过 `h.Use(...)` 串联，执行次序在 `chain.go` 注释中明确声明，新增横切能力需插入对应位置。
- 可缺失的后端（VectorStore、KB gRPC、Observability）以 nil 形式传入，路由层在注册时做条件判断或降级，保证网关在无某些依赖时仍可启动。
- 请求上下文通过 Hertz `c.Set` 传递 tenant_id/user_id/roles/scope，并由 `withTenantContext`/`withTenantContextStrict` 同步注入 Go context 供 RLS-aware store 消费。
- 错误统一通过 `respondError` 返回标准 JSON 错误体，并区分 `ErrInvalid`、`ErrUnsupported`、`ErrUnavailable` 等语义化错误类型。
