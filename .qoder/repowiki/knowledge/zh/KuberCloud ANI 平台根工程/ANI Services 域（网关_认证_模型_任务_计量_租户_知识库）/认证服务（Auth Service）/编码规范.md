- 所有 gRPC 错误通过 `google.golang.org/grpc/status` 包装为 `codes.*` 返回，未配置的功能统一返回 `FailedPrecondition` 或 `Unimplemented`。
- 配置项通过 `internal/config.Load()` 从环境变量读取并提供默认值，敏感密钥同时支持内联 PEM 字符串与文件路径两种方式。
- 对外部时间源使用可注入的 `now func() time.Time` 字段（如 `JWTValidator.now`、`oidcJWKSVerifier.now`），便于测试时替换。
- 数据库写操作统一以 `tx.Begin` + `defer rollbackTx` + `SetDBTenant` 模式包裹，确保事务回滚与租户隔离。
- 可选能力（JWT 校验器、OIDC 登录、刷新令牌、令牌黑名单）在构造时允许 nil，并在调用处做 nil 守卫后返回明确的 gRPC 错误码。
- API Key 以 `ani_<env>_<tenant_id>_<random>` 格式生成，仅对哈希值落库，原始 key 仅在创建时返回一次。
