单二进制入口 `main.go` 通过 `pkg/bootstrap` 连接 Postgres/NATS/Redis，并启动 gRPC server；配置集中在 `internal/config/config.go`，从环境变量加载数据库、缓存、JWT/OIDC 密钥等参数。

核心业务逻辑位于 `internal/service`，以 `AuthService` 为聚合根，组合以下子组件：
- `JWTIssuer`（`token_issuer.go`）：使用 RSA PKCS1v15 (RS256) 签发 tenant 与 platform 两类 access token。
- `JWTValidator`（`jwt.go`）：手动解析三段式 JWT，校验签名、时间窗口、issuer，并通过 `tokenBlocklist` 检查是否被撤销。
- `oidcLoginManager`（`oidc.go` + `oidc_sessions.go`）：实现 OIDC Authorization Code Flow，支持静态公钥与 JWKS 两种 ID Token 验证策略，状态与 session 分别持久化到 Redis 与 Postgres。
- `apiKeyStore`（`api_keys.go`）：管理 API Key 的创建、列表、撤销与速率限制（基于 Redis 计数器），key 以 `ani_<env>_<tenant>_...` 格式编码。
- `refreshTokenStore` / `passwordLoginManager` / `platformLoginManager`：分别处理刷新令牌、密码登录与平台账号登录。

依赖方向单向：`AuthService` → 各管理器 → DB/Cache；外部依赖通过 `pkg/bootstrap`、`pkg/adapters/postgres`、`pkg/ports` 注入，gRPC 接口由 `pkg/generated/pb/auth/v1` 定义。Dockerfile 使用多阶段构建，CGO_ENABLED=0 编译出静态 Alpine 镜像，暴露 GRPC 9101 与健康端口 9201。
