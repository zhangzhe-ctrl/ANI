- Helm values 采用分层结构：`global` 定义命名空间与镜像仓库，`infrastructure.profiles` 描述各部署模式开关，`services` 定义控制面服务镜像与端口，profile YAML 仅覆盖差异项。
- Manifest 目录按 `M1-<阶段>-<序号>` 命名（如 m1-infra-a、m1-instance-q），每个目录下文件以两位数字前缀（00/10/20…）强制 apply 顺序。
- 基础设施依赖统一以 external mode 接入，通过 `secretName: ani-bootstrap-placeholders` 及对应 key（database-url/nats-url/redis-url）注入连接信息，而非内嵌配置。
- 离线包通过 `core-package.yaml` 显式列出 images 与 charts 路径，并使用 sha256 digest 锁定镜像版本，确保可重复构建。
- 真实集群演练以 `-live-gate.yaml` / `-live-deps.yaml` / `-fixture.yaml` 后缀区分 Gate 用例、前置依赖与测试夹具，便于按 sprint 编号（sprint7~14）独立运行。
- 数据库迁移文件采用 `YYYYMMDD_NNN_name.sql` 时间戳命名规范，保证迁移顺序可追溯且幂等。
