- 每个 gRPC 服务按 `proto/<domain>/v1/<service>.proto` 命名，包名统一带 `v1` 后缀并通过 buf 配置豁免 PACKAGE_VERSION_SUFFIX lint。
- OpenAPI 文档在 `components.securitySchemes` 中统一定义 `BearerAuth`（JWT）与 `ApiKeyAuth`（X-API-Key）两种认证方案，并在请求级引用。
- 所有写操作通过 `Idempotency-Key` 请求头保证幂等，创建/更新端点的 schema 中显式声明该 header 为必填且长度 1..128。
- 列表接口统一返回 `{ items: [], next_cursor: string | null }` 形式的 cursor 分页结构，响应体包含 `total` 与 `next_cursor` 字段。
- 长耗时操作统一返回 202 + `AsyncTask` 响应体，并通过 `Location` Header 指向任务查询端点或由 Webhook 通知完成。
- 错误响应统一为 `{ code, message, request_id, details? }` 结构，并在 OpenAPI responses 组件中以 `BadRequest`/`Unauthorized`/`Forbidden`/`NotFound`/`Conflict` 等标准化响应复用。
- 兼容性基线文件对每个 path+method 快照记录 `operation_id`、`rbac_scope`、`request_body_required`、`request_schema` 与各状态码的 `schema`，以便 CI 检测破坏性变更。
