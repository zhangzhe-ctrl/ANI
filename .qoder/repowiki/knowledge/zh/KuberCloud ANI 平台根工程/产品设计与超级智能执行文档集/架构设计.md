文档按主题与用途分层组织：
- `ANI-boss-email-notification-docs/`：以 BOSS 邮件通知为单一特性导出完整文档包，包含 PRD（`prd/`）、SPEC（`spec/`）、UX（`ux/`）三件套，并通过 `references/` 交叉引用企业通知集成、运维 Webhook 及 TDesign UI 规范，根目录 `README.md` 作为索引说明各文件职责与仓库内外部依赖。
- `superpowers/plans/` 与 `superpowers/specs/`：AI agent 驱动的开发流程产物，plans 使用带 checkbox 的任务清单描述实施步骤、约束与验证命令，specs 提供对应的设计规格；两者通过日期前缀命名一一对应，形成“计划 → 设计”的单向依赖。
- `ops/scripts/`：面向开发者与 CI 的辅助脚本（如 `new-feature.sh` 创建 feature 分支、`prep-ai-batch.sh`、`sync-main.sh`），以及 GitHub 服务快速入门指南。
- 顶层 `start.bat` 提供 Windows 环境入口。
整体不耦合代码实现，仅通过路径与文件名约定关联到 `repo/api/openapi/services/v1.yaml`、`repo/architecture/*`、`repo/scripts/validate_*` 等真实工件，作为跨团队对齐与 AI 执行的权威文档源。
