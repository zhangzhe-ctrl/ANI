模块按 `core/` 与 `services/` 两个 API 层组织，每层内部再按 `go/`、`java/`、`python/`、`typescript/` 四个语言子目录平行展开，每个语言子目录均包含 `src/`（或包）、`examples/`、`smoke.*` 及可选的 `package.json` / `go.mod` 等构建清单。
- 单一事实源：每层根目录的 `sdk-metadata.json` 声明 `layer`、`title`、`version`、`serverURL` 以及完整的 `operations`、`schemas`、`idempotencyOperations`、`cursorPaginationOperations`、`errorCodes` 列表，是跨语言生成的唯一输入。
- 生成产物：各语言客户端文件首行标注 `Code generated by scripts/gen_sdk_alpha.py; DO NOT EDIT.`，将 metadata 中的 operationId 映射到方法名，并将 `Paths` 数组（如 `GET /instances/{instance_id}`）作为路由表驱动请求构造。
- 运行时 Client 抽象：Go 的 `anisdk.Client.Request(method, path, options)`、Python 的 `Client.request(method, path, body, params, headers)`、Java 的 `ApiClient`、TypeScript 的 `index.ts` 暴露统一签名，底层仅做 JSON 编解码、Bearer Token 注入、错误体解析为 `APIError`。
- 横切能力：通过 `IdempotencyOperations` / `IDEMPOTENCY_OPERATIONS` 列表在请求体中注入 `idempotency_key`；通过 `CursorPaginationOperations` / `CURSOR_PAGINATION_OPERATIONS` 列表提供 `cursor_params(limit, cursor)` 辅助函数；`ErrorCodes` 列表用于 `is_api_error_code` 判断。
- 依赖方向：SDK 仅依赖各自语言的 HTTP 标准库（net/http、urllib、okhttp/retrofit 风格、fetch），不反向依赖业务服务实现。
