- 每个能力域按“接口 + Request/Record/Result 结构体 + 枚举常量”组织在一个独立文件中，例如 workload_runtime、k8s_clusters、secrets 等均遵循此模式。
- 对外暴露的接口方法统一接收 `context.Context` 作为首参，并在上下文中传递 TenantID/UserID 等请求上下文信息。
- 幂等写操作在 Request 中显式携带 `IdempotencyKey` 字段（如 CreateCluster、CreateSecret、ApplyLifecycle 等），用于重试去重。
- 领域错误采用哨兵 error 变量（`ErrNotFound`、`ErrConflict`、`ErrUnauthorized` 等）配合 `errors.Is()` 判断，并通过 `types.Wrapf` 包装附加上下文而不破坏哨兵类型。
- HTTP 响应码通过 `types.HTTPStatusForError` 集中映射到 sentinel error，业务层只抛错不关心具体状态码。
- 租户上下文通过 unexported context key 的 `WithTenant`/`FromContext`/`TryFromContext` 三件套注入，缺失时 `FromContext` 直接 panic 以暴露编程错误。
