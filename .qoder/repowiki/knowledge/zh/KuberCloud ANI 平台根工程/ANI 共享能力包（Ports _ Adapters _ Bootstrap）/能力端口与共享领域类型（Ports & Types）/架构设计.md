本模块由两个并列子包构成清晰的依赖边界：
- `pkg/ports`：以 Go interface 形式声明所有外部能力契约，每个文件聚焦一个能力域（如 `workload_runtime.go` 定义 WorkloadRuntime/WorkloadInstanceService/WorkloadProviderApply 等一整套编排、渲染、准入、审计、状态协调、操作与身份绑定接口；`k8s_clusters.go`、`secrets.go`、`message_bus.go`、`cache_store.go`、`object_store.go`、`identity_provider.go`、`password_login.go`、`gpu_*`、`sandbox_*`、`storage_resources.go`、`network_resources.go`、`metering.go`、`observability.go`、`health.go`、`reconcile_controller.go`、`metadata.go` 等分别对应集群、密钥、消息总线、缓存、对象存储、认证、GPU、沙箱、存储/网络资源、计量、可观测性、健康检查、控制器、元数据等能力）。每个接口都附带 Request/Record/Result 结构体，形成“请求-记录-结果”的三段式契约。
- `pkg/types`：纯领域类型包，被 ports 与业务层共同引用，包含通用错误体系（`ANIError` + HTTP 状态映射 + `Wrapf`）、统一游标分页（`CursorPage[T]`、`ListRequest`、`EncodeCursor/DecodeCursor`）、以及带 RLS 注入能力的租户上下文（`TenantContext`、`WithTenant`、`FromContext`、`SetDBTenant`）。
依赖方向严格单向：业务服务 → ports 接口 → 具体 adapter 实现；types 不依赖 ports，仅被两者共享。错误通过 `ports/errors.go` 中的能力级哨兵错误与 `types/errors.go` 中的全局哨兵错误分层表达，避免直接返回底层 SDK 错误。
